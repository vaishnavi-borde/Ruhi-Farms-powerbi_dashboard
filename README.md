# 🌾 Ruhi Farms Dashboard

An interactive **Power BI Dashboard** developed for **Ruhi Farms** to analyze sales performance, revenue, customer trends, and key business metrics. The dashboard helps stakeholders make data-driven decisions by providing clear visual insights into farm operations and sales.

---

## 📊 Project Overview

The Ruhi Farms Dashboard transforms raw business data into meaningful visualizations, enabling users to monitor sales performance, identify trends, and evaluate business growth.

---

## ✨ Features

- 📈 Sales Performance Analysis
- 💰 Revenue & Profit Tracking
- 🛒 Product-wise Sales Analysis
- 📅 Monthly & Yearly Sales Trends
- 🌍 Region-wise Performance
- 📦 Category-wise Sales Distribution
- 📊 Interactive Filters and Slicers
- 📌 KPI Cards for Quick Insights

---

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- **Microsoft Excel / CSV**
- **Power Query**
- **DAX (Data Analysis Expressions)**

---

## 📂 Dataset

The dashboard is built using Ruhi Farms sales data containing information such as:

- Order Date
- Product Name
- Category
- Quantity
- Sales
- Profit
- Customer Details
- Region

## 📈 Dashboard Insights

The dashboard provides insights into:

- Total Sales
- Total Profit
- Total Orders
- Best Selling Products
- Highest Revenue Categories
- Monthly Sales Trend
- Regional Sales Performance
- Customer Purchase Patterns

## 🚀 How to Use

1. Clone this repository

```bash
git clone https://github.com/vaishnaviborde1309-coder/ruhi-farms-dashboard.git
```

2. Open the `.pbix` file using **Power BI Desktop**.

3. Refresh the dataset if required.

4. Explore the interactive dashboard using slicers and filters.
